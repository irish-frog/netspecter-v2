# NetSpecter Documentation Restructure

This package is a proposed replacement structure for the NetSpecter v2 `docs/` folder.

It separates documentation into:

- `deployment/` - install, update, setup, backup and troubleshooting guides.
- `network/` - bridge and network topology guidance.
- `integrations/` - AdGuard, Suricata, UniFi, Telegram and LCD integrations.
- `engineering/` - internal architecture, data flow, scaling, classification and IDS design notes.
- `business/` - licensing, hardware, repo positioning and documentation decisions.
- `history/` - compressed project history and archived handoff summaries.

Use `MIGRATION_MAP.md` to see where the old files should move.
